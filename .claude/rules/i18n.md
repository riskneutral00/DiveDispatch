## No hardcoded user-facing strings

Every string visible to users (labels, errors, toasts, placeholders, titles) must come from `useTranslations()`. Never write inline English in JSX or template literals for user-facing text. The only exception is dynamic loading fallbacks (`loading: () => <Spinner />`) where hooks can't run.

## Nine namespaces — no more

`common`, `errors`, `nav`, `auth`, `booking`, `portal`, `medical`, `waiver`, `app`. These are defined in `src/i18n/namespaces.ts`. Do not create new namespaces. If a key doesn't fit, it goes in `common` (generic) or its feature namespace.

## Transient errors use common.actionFailed

`common.actionFailed` is `"{action} failed. Try again."` — one template for all transient failures. Callers pass the action: `t('actionFailed', { action: t('save') })`. Do NOT create per-action error keys like `saveFailed`, `deleteFailed`, `generateLinkFailed`. Permanent-block errors (tokenExpired, bookingClosed, etc.) get their own key in `errors`.

## Sub-components own their translations

Every component that renders translated text calls `useTranslations()` directly. Never pass translated strings as props (`savedLabel`, `doneLabel`). The only exception is `label` props that describe _what_ the component displays (like `StepRow.label`), not _how_ to say a generic word.

## Date formatting uses browser locale

Never pass `'en-US'` to `toLocaleDateString()`. Use `undefined` (browser default respects the user's locale cookie) or `useFormatter()` from next-intl.

## New strings go in en.json first

Add the key to `messages/en.json`, then mirror to all 5 locale files. Run `npm run i18n:verify` to confirm parity. The verify script catches missing/extra keys.

## No string concatenation for user-facing text

Never use `` `${variable} deleted` `` or `"Error: " + message`. Use ICU templates: `t('roleDeleted', { role })`. Word order varies by language — concatenation breaks in zh/ko/th/fr.

## error-messages.ts is deleted

Error message constants no longer exist. Error codes map to i18n keys via `CODE_TO_KEY` in `convex-error.ts`. Use `parseConvexErrorI18n(err, t)` with `useTranslations('errors')`.
